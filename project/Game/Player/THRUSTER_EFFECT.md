# プレイヤー・スラスター光

## 実装場所

- `BoosterEffect.cpp`：`resources/vf-15c/thruster_left.obj` と `thruster_right.obj` を機体後部へ取り付け、速度に応じた噴射炎を描画します。
- `Player.cpp`：プレイヤー位置・姿勢・加速入力を毎フレーム `BoosterEffect` へ渡します。また、発光を加算合成で描画します。
- `GamePlayScene.cpp`：背景 → 不透明な機体・ノズル・地形 → 環境演出 → プレイヤーの噴射、の順で描きます。ゲーム／シミュレーション共通で停止中の噴射プレビューを更新します。
- `Trail.cpp`：円形断面で先端が細くなる白熱芯・ピンクの外炎・紫の光の3層を作ります。
- `Thruster.PS.hlsl`：照明に依存しない発光と柔らかい輪郭を描き、真後ろからも白熱芯が見える密度を保ちます。

## 見た目の作り方

1. 機体のローカル座標で左右のノズル位置を指定します。ゲームの移動前方は `+Z`、ノズルと噴射方向はカメラ側の `-Z` です。
2. 炎の頂点を機体ローカル座標で生成し、描画する機体と同じ最終クォータニオン・位置でワールドへ変換します。回避ロールも同じ姿勢を使い、過去のワールド座標への追従遅れを起こしません。
3. Blenderで配置したノズルOBJを左右別に読み込みます。モデル本体は不透明パスで描き、OBJの開口端のすぐ後ろから噴射します。
4. 最新のノズル位置を始点とする立体の炎を、移動中も停止中も生成します。
5. 初期設定では加速時に幅を約25%、長さを約18%増やし、光量も少し上げます。加速・解除は滑らかに切り替えます。白熱芯の初期値は外炎の52%の長さで、先端へ連続的に暗くなります。これらの倍率と芯の長さはImGuiで変更できます。
   通常カメラからも見えるよう、炎の幅と周辺光を強めています。後方視点でもピンクの外炎が薄くなりすぎない発光密度を保ち、位置確認用の黄色いマーカーは通常再生中には表示しません。
6. 炎は不透明な背景と地形を描いた後に加算合成（`SrcAlpha + One`）します。Z-Test有効・Z-Write無効・裏面カリングで前後関係を守り、余分な二重加算を抑えます。描画先のアルファを保つため、ImGuiのGame Viewでも炎の輪郭が暗く透けません。
7. カメラ更新が終わった後の描画直前に、機体・ノズル・炎の行列を同じカメラで再計算します。高速移動や急旋回でも投影フレームがずれません。

## 調整する値

`BoosterEffect.cpp` の `SetupBurnersForMode` にある `offset` がノズル位置です。`Update` 内の `targetLength` と `targetRadius` が長さと半径の目標値です。`Trail.cpp` の `layers` にある半径比・長さ比・発光色で芯と外炎を調整します。位置補正とその保存方法は従来どおりです。

## 編集中の確認

「ゲーム」「シミュレーション」のどちらでも、ツールバーの「編集に戻す」で停止すると、実際の炎とチューブを出力65%でプレビューします。「設定一覧 → スラスター位置 → 加速状態をプレビュー」で通常と加速を比較できます。切り替え時のプレイヤー再初期化直後にも炎を準備します。機体や敵は停止したまま、カメラ移動と位置補正で発生位置を確認できます。

同じ画面の「エフェクトの見た目」で、幅（0.25〜6倍）・長さ（0.25〜4倍）・明るさ・周囲の光をリアルタイム調整できます。「加速・白い芯の調整」では加速時の幅と長さの倍率、芯の長さ比率を設定します。幅と長さは独立しており、幅だけを増やしても炎が長くなることはありません。

「スラスター設定を保存」で位置と見た目を `resources/vf-15c/thruster_position.json` に保存し、次回起動時も読み込みます。「保存設定を読み込む」で現在のゲームにも適用します。以前の位置のみのJSONでは見た目の初期値を使用します。位置とエフェクトはそれぞれ個別にリセットできます。

## 付着の回帰テスト

`tools/tests/thruster_attachment_test.vcxproj` を Debug/x64 でビルドして実行します。実際の `Trail.cpp` を使い、急な位置移動・ピッチ・ヨー・全周ロールの120姿勢と6ノズルで、炎の根元とOBJノズル開口のワールド座標が一致することを検査します。古い位置履歴の破棄・頂点の有限性・後方への噴射も検査します。
保存設定の往復・旧JSON互換性・範囲制限・不正入力の拒否・幅と長さの独立性も検査します。
